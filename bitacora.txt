HTML – La estructura
HTML permite organizar el contenido de la página: títulos, textos, imágenes y secciones.

Ejemplo: crear el título principal y la descripción de Rueda Libre.
<h1>Rueda Libre</h1>


CSS – El diseño visual
CSS permite darle estilo a la página: colores, tamaños, distribución, tipos de letra y efectos visuales.

Ejemplo: hacer que el título sea verde y esté centrado.
h1 {
    color: green;
    text-align: center;
}


3. JavaScript – La interactividad
JavaScript permite que la página responda a las acciones del usuario, por ejemplo, mostrar mensajes o validar información.

Ejemplo: mostrar un mensaje cuando una persona quiera alquilar una bicicleta.
alert("¡Gracias por elegir Rueda Libre!");
